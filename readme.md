Repositori ini digunakan untuk mendokumentasikan, mengelola kode sumber kustom (*custom page templates*, *snippets*, *stylesheets*, dan skrip) dari website **[Lepas Kunci Lombok](https://lepaskuncilombok.com/)**.

Meskipun website diproduksi dan dikelola menggunakan CMS **WordPress**, repositori Git ini berfungsi sebagai **Version Control System (VCS)** untuk memudahkan pelacakan perubahan (*tracing/versioning*), dokumentasi arsitektur halaman, serta pemeliharaan kode secara terstruktur.

## 📌 Ringkasan Proyek & Profil Bisnis

* **Nama Perusahaan**: CV Lepas Kunci Lombok
* **Website Resmi**: [https://lepaskuncilombok.com/](https://lepaskuncilombok.com/)
* **Lokasi Operasional**: Pelembak, Jl. Koperasi No. 178, Pejeruk, Kec. Ampenan, Kota Mataram, Nusa Tenggara Barat 83511
* **Layanan Utama**:
  * **Sewa Mobil Lepas Kunci**: Sewa mobil tanpa driver (24 jam) untuk fleksibilitas perjalanan mandiri di Lombok.
  * **Sewa Mobil + Driver + BBM**: Layanan pengemudi berpengalaman (12 jam/hari) untuk perjalanan wisata, keluarga, atau dinas.
  * **Antar-Jemput (Airport Transfer)**: Layanan penjemputan & pengantaran ke Bandara Internasional Lombok (LOP), Pelabuhan Bangsal, Pelabuhan Lembar, Senggigi, Kuta Mandalika, hingga Sembalun.
  * **Paket Tour & Wisata**: Paket perjalanan keliling destinasi populer di Lombok.

## 🛠️ Tech Stack & Infrastruktur

* **CMS**: WordPress
* **Bahasa Pemrograman**: PHP (Theme/BeTheme Template & Snippets), HTML5, CSS3, JavaScript
* **Theme Structure**: WordPress Custom / BeTheme
* **Performance & DNS**: Cloudflare CDN & DNS Management
* **Database**: MySQL / MariaDB
* **Integrasi Utama**: WhatsApp Business API / Click-to-Chat Direct Booking
